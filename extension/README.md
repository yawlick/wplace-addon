# Wplace Auto Color

Chromium-расширение для ручного рисования на `wplace.live`: пользователь физически
держит `Q` и двигает мышью, а расширение для каждой новой позиции выполняет штатный
цикл выбора цвета и добавления пикселя.

Расширение не вызывает API рисования, не отправляет `fetch`/XHR и не изменяет POST-запросы.
Расширение перехватывает штатные обработчики компонента рисования в MAIN world и вызывает
их напрямую. Сетевые запросы, кнопку окончательной покраски и service worker сайта оно
не подменяет.

## Установка

1. Открой `chrome://extensions` или `edge://extensions`.
2. Включи «Режим разработчика».
3. Нажми «Загрузить распакованное расширение».
4. Выбери папку `G:\wplace-addon\extension`.
5. Обнови уже открытую вкладку `wplace.live`.


## Использование

- `F8` включает и выключает автоматизацию.
- Удерживай физический `Q` и веди курсор по canvas карты.
- Задержки меняются в панели справа.
- При отпускании `Q`, скрытии вкладки или выключении режима очередь очищается.

## Как обеспечивается порядок

Первое настоящее `mousemove` передаётся сайту. Пока его цикл выполняется, следующие
физические перемещения сохраняются как последняя ожидающая позиция, но временно не
меняют hover сайта. Для зафиксированной точки выполняется атомарный цикл:

1. штатный обработчик движения получает зафиксированную точку;
2. штатный обработчик СКМ выбирает цвет шаблона;
3. штатные обработчики `Space DOWN` и `Space UP` добавляют пиксель в selection.

Кнопка «Выбрать прямоугольник» принимает два клика по противоположным углам. Координаты
переводятся через настоящий MapLibre instance и сетку текущего сезона сайта. Пиксели
обходятся змейкой и добавляются в обычный список выбранных; финальную покраску запускает
пользователь штатной кнопкой сайта.

После первого клика показывается контур прямоугольника до текущего положения курсора.
При каждом новом выделении расширение обнуляет счётчики прохода и снимает один
кадр пиксельного слоя карты штатным способом сайта: после `render` читает
`map.getCanvas()`. Цвет сравнивается с палитрой из свежих исходников сайта;
модуль палитры не импортируется до готовности локализации. Пиксели, успешно
отправленные штатной кнопкой сайта за последние 10 минут, также не выбираются
повторно, пока цвет шаблона не изменился. Дополнительных запросов за цветами
карты расширение не делает.

Одновременно работает только один цикл. По умолчанию буфер равен одной точке и постоянно
заменяется самой свежей позицией, поэтому расширение не догоняет устаревший путь. Размер
буфера можно увеличить вручную, если плотность линии важнее отзывчивости.

## Ограничение первой версии

MapLibre instance сайта не опубликован в DOM или `window`, поэтому панель показывает
экранную точку, а не внутреннюю координату пикселя. Очередь всё равно привязывает выбор
цвета и рисование к одной и той же зафиксированной координате. Реальную реакцию сайта
на синтетические события нужно проверить в авторизованной сессии с активным шаблоном.
